Hypergraph signal tensor corresponding to the signal vector signal. The tensor is an M-way N × 1 × N × ⋯ × N tensor where N is the length of signal. The array is not materialized in memory.

HypergraphSignals.Hypergraph — Type
Hypergraph(hyperedges, nvertices = maximum(maximum, hyperedges))

Form a hypergraph from a collection of hyperedges (each a collection of vertex indices), where nvertices and the maximum cardinality are inferred. Use Hypergraph{M}(hyperedges, nvertices) when hyperedges is empty.

source
HypergraphSignals.Hypergraph — Type
Hypergraph{M}(hyperedges, nvertices)

Form a hypergraph stored as a Set of hyperedges, each of which is a Set of at-most M vertex indices from 1:nvertices. The hyperedges can be any collection of collections of vertex indices, and are copied into a new Set{Set{Int}}.

Fields

  • hyperedges::Set{Set{Int}}: set of hyperedges
  • nvertices::Int: number of vertices in the hypergraph

HypergraphSignals.hgfilter — Method
hgfilter(A::Array{TA,M}, x::Vector{Tx}) where {TA<:Real,Tx<:Real,M}

Perform a t-HGSP shift of the x vector using the shift A tensor, then fit a hypergraph signal to the output tensor.

Only M <= 3 is currently supported (see hgsignalfit). For M = 3, the output signal is only determined up to sign.

HypergraphSignals.hgsignalfit — Method
hgsignalfit(X::Array{T,M}) where {T<:Real,M}

Fit a hypergraph signal to the tensor X.

Only M <= 3 is currently supported. For M = 3, the signal is obtained from the leading eigenpair of the (symmetrized) N × N matrix X[:, 1, :], so it is only determined up to sign.

source
HypergraphSignals.hgsym — Method
hgsym(A::Array{T,M}) where {T<:Real,M}

t-HGSP symmetrization of dense tensor A.

Note that this only performs a symmetric expansion of A along modes 3:M, so the output may not be symmetric (e.g., when A is not symmetric along modes 1 and 2).

HypergraphSignals.teigen — Method
teigen(A::Array{T,M}) where {T,M}

t-eigendecomposition of dense tensor A implemented via FFT. For matrices (M = 2), this is the usual eigendecomposition.

Only t-self-adjoint tensors (i.e., A == tadjoint(A)) are currently supported, for which every Fourier-domain frontal slice is Hermitian. The eigenvalues of each slice are then real and sorted in ascending order, and the eigenvalue tensor Λ is real when A is real.

source
HypergraphSignals.tmul — Method
tmul(A::Array{TA,M}, B::Array{TB,M}) where {TA,TB,M}

t-product of dense tensors A and B implemented via FFT. For matrices (M = 2), this is the usual matrix product. The output is real when both A and B are real.
